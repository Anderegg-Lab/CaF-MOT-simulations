# CaF-MOT-simulations
SSE/MCWF simulations of a CaF DC MOT used in arXiv:2605.30296

2b.jl and paper_version_testing.ipynb can be used as examples for code usage. 2b.jl was used to create the data in figure 7 of the paper.
